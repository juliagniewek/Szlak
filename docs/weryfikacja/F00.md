## Nowe uwagi (INFO), bez wpływu na werdykt
**I8 · Migracja bez kopii i tak zapisuje dane.** `src/magazyn.js:122–126` pomija wynik `zachowajKopie` przy migracji: gdy kopii nie da się zapisać, dane i tak zostają zmigrowane i zapisane, bez kopii oryginału i bez komunikatu. Dziś to nieosiągalne (`WERSJA` = 1, brak migracji). Do rozstrzygnięcia przy pierwszej migracji (`WERSJA` 2): migrować bez kopii czy działać tylko w pamięci. Odtworzenie (atrapa, która nie przyjmuje kopii):
```
node --input-type=module -e "import * as m from './src/magazyn.js'; const b = m.atrapaPamieci({ [m.KLUCZ]: JSON.stringify({ wersja: 1, zapisane: [], podroze: [] }) }); const p = { ...b, setItem: (k, v) => { if (k.startsWith(m.KLUCZ_KOPII)) throw new Error('brak miejsca'); b.setItem(k, v); } }; const w = m.wczytaj(p, { wersja: 2, migracje: { 1: (d) => ({ ...d, wersja: 2 }) } }); console.log('ostrzezenie:', w.ostrzezenie, '| dane:', b.getItem(m.KLUCZ), '| kopia:', b.getItem(m.KLUCZ_KOPII));"
```
Wynik: `ostrzezenie: null | dane: {"wersja":2,…} | kopia: null`.
